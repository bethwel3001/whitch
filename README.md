# w!tch

w!tch is an AI-powered movie and TV show recommendation application. It provides personalized suggestions based on your mood and allows you to chat with an AI expert about any movie.

## Key Features

- **Mood-Based Recommendations**: Get movie and show suggestions tailored to how you are feeling.
- **AI Movie Chat**: Ask questions, get fun facts, and discuss plot details with an AI movie expert.
- **Minimalist Design**: A clean and simple interface built for a seamless user experience.
- **Responsive**: Works beautifully on desktop and mobile devices.

## Tech Stack

- Next.js (App Router)
- React
- Tailwind CSS
- ShadCN UI
- Genkit (for Generative AI)

## Getting Started

To get the application running on your local machine, follow these steps:

1.  **Install Dependencies**

    ```bash
    npm install
    ```

2.  **Run the Development Server**

    ```bash
    npm run dev
    ```

3.  Open [http://localhost:9002](http://localhost:9002) in your browser to see the application.
