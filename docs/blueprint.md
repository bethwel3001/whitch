# **App Name**: CineMatch

## Core Features:

- Personalized Recommendations: Suggest movies and shows based on viewing history and mood using AI to understand user preferences.
- Streaming Service Filters: Filter movies and shows by streaming service availability.
- List Sharing: Allow users to share and compare movie lists with friends.
- User Profile: Store user preferences, viewing history, and friend lists.
- Mood Selection: Tool to let users select their current mood to refine movie/show suggestions; AI considers mood when making recommendations.

## Style Guidelines:

- Primary color: Deep indigo (#4B0082) for a cinematic and immersive feel.
- Background color: Dark gray (#222222) to enhance contrast and readability.
- Accent color: Electric purple (#BF00FF) to highlight interactive elements.
- Headline font: 'Space Grotesk' sans-serif for a modern, techy headline.
- Body font: 'Inter' sans-serif for clear, readable content.
- Use flat, minimalist icons with the electric purple accent color to represent different genres and streaming services.
- Employ a grid-based layout for displaying movie posters and information in a visually appealing manner.
- Implement subtle animations for transitions and interactions to enhance user experience.
